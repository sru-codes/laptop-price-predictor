# Minor Project 1: Laptop Price Predictor

## Objective
Predict laptop prices based on specifications like RAM, processor, and brand using Linear Regression.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn (Linear Regression)
- Matplotlib/Seaborn for visualization

## Implementation Steps
1. Create a synthetic dataset or find a small sample dataset.
2. Preprocess data: handle categorical variables (brand, processor) using One-Hot Encoding.
3. Split data into training and testing sets.
4. Train a Linear Regression model.
5. Evaluate the model using Mean Squared Error and R-squared.
6. Save the model and create a simple prediction script.
