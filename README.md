# Laptop Price Predictor

This is a minor project that predicts laptop prices based on specifications like RAM, Storage, and Processor Speed using Linear Regression.

## Features
- Data preprocessing with One-Hot Encoding.
- Linear Regression model for price estimation.
- Model evaluation with MSE and R-squared.

## How to run
1. Install dependencies: `pip install pandas scikit-learn joblib`
2. Run training script: `python train.py`
